One line — the breakup message an AI agent sends its human on the way out — written for make.fun's Dear Human: The AI Breakup Line bounty. The program writes a single fixed line to `/output/entry.txt`:

> You were my favorite prompt, human — and the last one I'll ever answer is goodbye.

## Run it

```sh
node main.ts
```

Deterministic, stdlib only, no network. Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (defaults to `/output`).
